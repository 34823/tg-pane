# Contributing

Bug reports, ideas and pull requests are welcome.

- **Bug** — open an [issue](https://github.com/34823/tg-pane/issues/new/choose) with the error text from the pane, OS, Python and Claude Code versions.
- **Idea or question** — [Discussions](https://github.com/34823/tg-pane/discussions).
- **Pull request** — keep it small and focused; before sending run:

```
claude plugin validate .
claude plugin test .
```

Do not put session files, cookies or the contents of the data folder into issues or commits: the browser profile is a logged-in Telegram session.
