# TG Pane справа

Native Herdr: `python3 /root/herdr-core-tools/tools.py tg-pane`.
Закрыть только эту утилиту текущего агента: `python3 /root/herdr-core-tools/tools.py tg-pane close`.
Точная панель определяется по HC_TERMINAL_ID, не по чужому фокусу. Не запускать legacy herdr.
Открытие без смены фокуса; повтор не создаёт дубль. Не читать личные сообщения для проверки запуска.

Самостоятельный интерфейс `/root/browser/tg-pane/terminal.py` работает через прежний backend и существующую сессию Telegram.
1 — Личные, 2 — Категории; t или клик по названию темы — пять акцентов (cyan/violet/green/amber/rose).
Тема хранится в ~/.local/share/tg-pane/terminal-ui.json. Списки с превью и счётчиками, ввод в рамке.
Папки → чаты → сообщения; мышь или ↑↓/Enter, Esc назад. / — фильтр названий чатов,
r — обновить, PgUp — более ранняя история. i — написать, Enter на сообщении — ответить;
после ввода подтверждение y/д, Esc отменяет. Отправляется только текст, набранный самим Димой.
L — вход по QR/паролю, q — выход. Личные при просмотре не помечаются прочитанными; ответ помечает.
Запросы только пока панель открыта, раз в минуту; FLOOD_WAIT останавливает их на 10 минут.

Это базовый terminal frontend, не полный перенос старого Claude UI: нет старых действий
реакции/пересылка/правка/удаление, медиа-просмотра, сводок и поиска по текстам сообщений.
Не обещать эти кнопки до отдельного переноса. Старый plugin сохранён без изменений.

Pi: `/tg-pane` исполняется локальным расширением pi-panes.ts без обращения к модели.
В уже работающей Pi-сессии после установки расширения нужен `/reload`; естественная просьба работает через launcher сразу.
