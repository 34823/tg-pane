# TG Pane справа

Native Herdr: `python3 /root/herdr-core-tools/tools.py tg-pane`.
Закрыть только эту утилиту текущего агента: `python3 /root/herdr-core-tools/tools.py tg-pane close`.
Точная панель определяется по HC_TERMINAL_ID, не по чужому фокусу. Не запускать legacy herdr.
Открытие без смены фокуса; повтор не создаёт дубль. Не читать личные сообщения для проверки запуска.

Самостоятельный интерфейс `/root/browser/tg-pane/terminal.py` работает через прежний backend и существующую сессию Telegram.
Открывается список всех чатов. 0/1/2 — Все / Личные / Папки; t или кнопка «Тема» — пять акцентов.
Тема хранится в ~/.local/share/tg-pane/terminal-ui.json. От 64 колонок — чаты слева, переписка справа;
ниже — список и чат по очереди, кнопка ‹ возвращает список. Свои сообщения справа, входящие слева.
Всё через мышь: вкладки, папки, чаты, поиск над списком (фильтрует сразу), поле ввода,
«Ответить»/двойной клик по сообщению, «Отправить» (сразу, без подтверждения), обновление,
«Раньше»/«К новым», тема, выход и вход при ошибке авторизации. Колесо листает область под мышью.
Один клик выделяет сообщение (▸), не начинает ответ. Поле ввода текста требует клавиатуру.
Папки → чаты → сообщения; мышь или ↑↓/Enter, Esc назад. / — фильтр названий чатов,
r — обновить, PgUp — более ранняя история. i — написать, Enter на сообщении — ответить;
Enter в поле ввода сразу отправляет (решение Димы 31.10.2026), Esc выходит из ввода.
Отправляется только текст, набранный самим Димой; пока отправка идёт, повторный клик не дублирует её.
L — вход по QR/паролю, q — выход. Личные при просмотре не помечаются прочитанными; ответ помечает.
Запросы только пока панель открыта, раз в минуту; FLOOD_WAIT останавливает их на 10 минут.

Фото, изображения и превью видео в видимой истории загружаются через tgmedia.py без отметки прочтения; цветное растровое превью прямо в сообщении, нажатие открывает крупнее, Esc/× закрывает. Это терминальная растеризация в 256 цветов, не полноразмерное фото; видео не проигрывается. Кэш — в data/media. Для текущей панели после обновления кода нужно переоткрытие.

Это базовый terminal frontend, не полный перенос старого Claude UI: нет старых действий
реакции/пересылка/правка/удаление, проигрывания видео, сводок и поиска по текстам сообщений.
Не обещать эти кнопки до отдельного переноса. Старый plugin сохранён без изменений.

Pi: `/tg-pane` исполняется локальным расширением pi-panes.ts без обращения к модели.
В уже работающей Pi-сессии после установки расширения нужен `/reload`; естественная просьба работает через launcher сразу.
